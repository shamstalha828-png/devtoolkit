# DevToolkit

A lightweight, privacy-friendly collection of free developer tools that run entirely in the browser.

## Features

- JSON formatting, minification, and syntax validation
- Unicode-compatible Base64 encoding and decoding
- Secure random password generation using the browser's cryptographic random number generator
- Live character, word, and line counting
- Responsive dark-mode interface

## Run locally

Clone or download the repository, then open `index.html` in a modern browser. No installation, build step, account, or server is required.

## Deploy

Publish the repository using GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**. Your site will then be hosted at your GitHub Pages URL.

## Privacy

All operations are performed locally in your browser. This project does not send entered text or generated passwords to a server. Avoid pasting sensitive data into any site you do not trust.
