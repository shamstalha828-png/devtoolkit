# Contributing

Thanks for your interest in improving DevToolkit!

1. Open an issue describing the bug or proposed improvement before large changes.
2. Fork the repository and create a focused branch.
3. Make your changes using plain HTML, CSS, and JavaScript.
4. Test the feature in a current desktop and mobile browser, including invalid inputs.
5. Open a pull request describing what changed and how you tested it.

Please be respectful and never include secrets or private data in issues or pull requests.
